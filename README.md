# スイカン面接評価アプリ（独立版）

Googleアカウント・Claudeアカウントとも無関係に動く、独立したWebアプリです。
面接官はログイン不要でURLを開くだけで評価を入力でき、送信すると自動で加重採点・合否判定・DISCタイプ判定が行われます。

構成:
- フロントエンド（画面）: GitHub Pages（無料・独立ホスティング）
- データ保存: Supabase（無料、Googleとは無関係の独立サービス）

すでにセットアップ・デプロイは完了しています。公開URLは以下の通りです。

- 面接官用フォーム: https://ryoya61.github.io/sukan-interview-app/index.html
- 管理者用結果一覧: https://ryoya61.github.io/sukan-interview-app/results.html

ファイル構成:
- `index.html` … 面接官が使う評価入力フォーム
- `results.html` … 管理者用の結果一覧画面（パスフレーズで保護、詳細画面は色分け・グラフ表示対応）
- `config.js` … Supabaseの接続情報（設定済み）
- `supabase_setup.sql` … Supabase側で実行済みのセットアップSQL（参照用）

## ⚠️ 運用開始前に必ず行うこと：パスフレーズの設定

セキュリティ上の理由から、結果一覧を見るための合言葉（パスフレーズ）は私が代わりに入力することができません。
運用を始める前に、必ずご自身で以下の手順を行ってください（1分程度で終わります）。

1. https://supabase.com/dashboard/project/nyzgextixpftsrtqknkx/sql/new を開く（ログイン済みのはずです）。
2. 以下のSQLをコピーして貼り付け、`'新しい合言葉'` の部分をご自身の好きなパスフレーズに書き換えます（例: `'sukan2026kanri'`）。

```sql
insert into app_secrets (key, value)
values ('admin_passphrase_hash', crypt('新しい合言葉', gen_salt('bf')))
on conflict (key) do update set value = excluded.value;
```

3. 右下の「Run」を押して実行します。エラーが出なければ完了です。
4. これで `results.html` にアクセスするとき、この合言葉でログインできるようになります。

## 動作確認済みの内容

- テストデータを1件送信し、加重採点（44点/88%/最小3点/◎判定）とDISCタイプ判定（D主導型）が正しく計算・保存されることを確認済みです。
- 結果一覧の閲覧が、正しい合言葉のときだけデータを返すこと（間違った合言葉では0件）を確認済みです。
- 面接官側から直接データベースを読み取ろうとしても拒否されること（閲覧はRPC経由のみ）を確認済みです。
- テスト行はすでにデータベースから削除済みです。
- 結果詳細画面は、点数の色分け・DISCタイプの棒グラフ・評価8項目の棒グラフなど、振り返り時に見やすいデザインへ刷新済みです。

## 運用方法

- 面接官には面接官用フォームのURLを共有してください。ログイン不要でそのまま入力できます。
- 人事担当者は管理者用結果一覧のURL＋上記で設定した合言葉で、いつでも一覧・詳細・CSVダウンロードができます。
- 合言葉を後から変更したい場合は、上記と同じSQLを新しい合言葉で再実行してください。

## 質問内容・評価基準を編集したいとき

`index.html` 内の質問文・評価項目の配列を書き換えることで変更できます。GitHub上で直接編集するか、私に依頼してください。

## セキュリティについての補足

- 面接官側（入力フォーム）は誰でも新規データを追加できますが、既存データの閲覧・変更・削除はできません。
- 結果一覧の閲覧は、Supabase側で合言葉が正しいと確認できた場合のみサーバー側でデータを返す仕組み（RPC関数）になっており、合言葉を知らない人がデータベースに直接アクセスしても中身は見えません。
- より高いセキュリティが必要な場合（例: 採用担当者ごとにログインを分けたい等）は、Supabase Authを使った本格的なログイン機能への拡張も可能です。必要であればお知らせください。
